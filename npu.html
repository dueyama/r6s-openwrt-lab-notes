用語の補足
受動観察 / 受入
受動観察は異常度を記録・表示する段階。受入は、その用途へ進めるために定めた条件で確認すること。
特徴量 / Kitsune
通信の大きさ・間隔などを数値化した入力が特徴量。Kitsuneはその統計から通信の外れ具合を評価する方式。
学習 / 推論 / 固定モデル
学習はデータからパラメータを決める工程。推論は学習済みモデルで値を計算する工程。固定後は観察中に再学習しない。
FM / AD
FMは特徴を小グループへ分ける学習、ADはその後に異常検知器を学習する段階。
CPU64 / FP16
CPU64は64ビット浮動小数点の参照計算。FP16は16ビット浮動小数点形式で、数値差を別途確認する。
MI / H / HHjit / HH / HpHp
115特徴の集計対象を表す分類名。装置の識別、ホスト、通信間隔、ホスト対、ポートを含む通信対などの統計を扱う。
driver / runtime / SDK
driverはOSとNPUをつなぐソフト、runtimeはモデル実行側のソフト、SDKは開発・変換用の道具。
IOMMU / device tree
IOMMUは装置からのメモリアクセスを管理する機構。device treeはLinuxへ機器構成を伝える記述。
LUT / sigmoid / NHWC
LUTは計算結果の参照表、sigmoidはモデル内の数値変換関数、NHWCは入力配列の配置形式。
receipt（確認記録）
対象の版・根拠・結果を結び付けて残す記録。存在だけで実機導入や全工程の完了を示すものではない。
正式finish（工程の受入完了）
必要な原本・API・画面証跡などをそろえた工程上の完了。ソフトの全問題を直したという意味ではない。
投影 / 再結合
投影は保存ログを集計・表示用データへ整形すること。再結合は監査結果を対応する構成・版の根拠へ結び直すこと。
