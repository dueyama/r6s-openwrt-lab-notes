# NanoPi R6S OpenWrt Lab Notes

This bilingual field journal follows a home router built around the NanoPi R6S and OpenWrt. It documents the hardware choices, software changes, security reviews and experiments with the board’s neural processing unit (NPU). Each experiment describes what was tested, what happened and which questions remain open.

**Want to try an idea on your own hardware?** Open *Start with AI* and give the prompt at the top to your AI assistant. Tell it which board you have and what you want to try. The guide helps you adapt the experiment to your setup.

- [Read the lab notes in English](https://dueyama.github.io/r6s-openwrt-lab-notes/en.html)
- [Start with AI](https://dueyama.github.io/r6s-openwrt-lab-notes/start-en.html)
- [Daily security reviews and verified fixes](https://dueyama.github.io/r6s-openwrt-lab-notes/audits-en.html#daily-verified-fixes)

The `docs/` directory contains the website files served by GitHub Pages. The R6S NPU implementation has its own repository. [NPU implementation](https://github.com/dueyama/openwrt-r6s-rknpu)

## 日本語｜NanoPi R6S OpenWrt実験記

NanoPi R6SとOpenWrtで家庭用ルーターを構成し、機材を選んだ理由、ソフトウェアの変更、日々のセキュリティ監査、内蔵NPUを使った実験を記録しています。各実験では、試した条件、得られた結果、まだ確かめられていない点を追えます。

**手元の機材で試してみたい方へ。** 「AIと始める」を開き、冒頭のプロンプトをAIアシスタントに渡してみてください。「手元のRaspberry Piで通信の記録から試せる？」のように、機種と興味のあることを添えると、自分の環境に合わせて始められます。
